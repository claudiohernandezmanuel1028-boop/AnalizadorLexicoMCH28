# Analizador Léxico ClaudioComp

Analizador léxico desarrollado utilizando FLEX y Python,
con una interfaz gráfica para analizar código del lenguaje
ClaudioComp.

## Objetivo

El proyecto permite identificar los tokens definidos para
ClaudioComp y detectar errores léxicos, mostrando los
resultados mediante una interfaz gráfica.

## Tecnologías utilizadas

- FLEX 2.6.4
- Python
- Tkinter
- C
- GCC

## Ejecución

Para ejecutar la aplicación, se debe abrir:

Ejecutar.bat

## Estructura del proyecto

- `src/` — contiene las reglas del analizador y el código generado.
- `build/` — contiene el ejecutable del analizador.
- `examples/` — contiene archivos de prueba.
- `docs/` — contiene la documentación del lenguaje.
- `main.py` — interfaz gráfica.
- `build_lexer.bat` — genera y compila el analizador.
